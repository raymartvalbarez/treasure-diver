# Treasure Diver (sample)

Bago NHS ADM math game — swim underwater and open the chest with the correct integer.

**Live:** https://raymartvalbarez.github.io/treasure-diver/  
**Demo (no scores):** https://raymartvalbarez.github.io/treasure-diver/?demo=1  
**Projector board:** https://raymartvalbarez.github.io/treasure-diver/leaderboard.html

Sibling of [Integer Archer](https://raymartvalbarez.github.io/integer-archer/). Separate MantleDB namespace `bnhs-tdiver-nov10-2026`.

## Controls
- **Swim:** drag / hold finger — diver follows; arrow keys / WASD on PC.
- **Tap chest:** with checkbox on, tap a numbered chest to auto-swim to it.
- Wrong chest / shark / jellyfish / time-up loses a life — correct answer is never shown.
